System Architecture & Engine Operational Specifications

Institutional microstructural backtesting and execution fidelity breakdown

Microstructure Engine Active
1. Continuous Data Feed

Ingests historical CME continuous futures (MNQ=F / NQ=F) datasets. Reconstructs intraday 1-minute price bars via Brownian Bridges and Merton Jump-Diffusion to model fat-tailed volatility and opening gaps.

  • • Tick Size: 0.25 pt ($0.50/contract)
  • • Multiplier: $2.00 per full point
  • • Timezone: America/New_York (ET)
2. 40-Tick Intra-Bar Engine

Each historical candle is decomposed into a 40-tick micro-auction path (Open → Noise → Extreme 1 → Retracement → Extreme 2 → Close). Evaluates Stop Losses & Take Profits on actual sub-bar price flow rather than static bar endpoints.

  • • Quantization: Exact 0.25 tick steps
  • • SL Priority: Conservative double-touch
  • • Intrabar Stops: Tick-level bracket tracking
3. Real-World Execution Lag

Enforces zero lookahead bias (process_orders_on_close = false). Signals finalized at Bar N Close are queued and filled at Bar N+1 Open, applying realistic bid/ask spread crossing and latency.

  • • Commissions: $1.24 / round-trip
  • • Slippage: 1.0 tick ($0.50 crossing)
  • • Fill Model: Next-bar open market fill
4. Risk & Monte Carlo Suite

Executes native Python translations of TradingView PineScript v5 ASTs. Evaluates Parametric 95% / 99% VaR, CVaR, Sharpe, Sortino, and performs Stationary Bootstrap Monte Carlo simulations across crisis regimes.

  • • Regimes: COVID, Fed Bear, Volmageddon
  • • Resampling: Block & Stationary Bootstrap
  • • Ruin Risk: Equity drawdown confidence
